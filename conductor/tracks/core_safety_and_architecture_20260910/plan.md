## Фаза 1: Устранение критических рисков безопасности и целостности данных (P0 Fixes)

- [x] **Задача 1.1: Защита Git Worktree от деструктивного перезапуска**
  - **Описание:** В `electron/main.ts` в обработчике `start-task` убрать безусловное удаление ветки (`git branch -D`) и рекурсивное удаление папки worktree. Если worktree уже существует, использовать его или переподключаться без потери данных.
  - **Файлы:** `electron/main.ts`
  - **Верификация:** Проверка логики создания существующего worktree. `git status` и проверка наличия файлов после перезапуска.

- [x] **Задача 1.2: Безопасное завершение процессов задачи (Targeted Process Termination)**
  - **Описание:** В `electron/main.ts` заменить команду `pkill -9 -f` на проверку и завершение конкретного PID (например, через `process.kill(pid)` или `kill -9 <pid>` с валидацией числового PID).
  - **Файлы:** `electron/main.ts`
  - **Верификация:** Запуск фонового процесса с проверкой, что команда завершает строго указанный PID без системного pkill.

- [x] **Задача 1.3: Исправление маршрутизации задач и репозиториев**
  - **Описание:** В `src/store.ts` в методе `selectTask(taskId)` синхронизировать `activeRepoId = task.repoId`. Изолировать добавление логов, чтобы логи задачи не попадали в чужие задачи.
  - **Файлы:** `src/store.ts`
  - **Верификация:** Проверка `useStore.getState().activeRepoId` после `selectTask`.
