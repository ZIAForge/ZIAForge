# Определение продукта: ZIAForge (ZIAF)

## 1. Концепция и Видение
ZIAForge (ZIAF) — это открытый локальный ИИ-оркестратор и среда разработки десктопного уровня с подключениями BYOK/BYOS (Bring Your Own Key / Bring Your Own Subscription), последовательным планом, проверкой результатов и решениями пользователя.
Система позволяет разработчикам использовать личные подписки (Claude Pro, Google Antigravity, OpenAI/ChatGPT) и локальные модели (Ollama, vLLM) без переплат сторонним сервисам, обеспечивая полную локальную изоляцию данных и безопасность разработки.

## 2. Ключевые ценности
1. **Прозрачность мышления (Glass-Box AI):** Полный посимвольный стриминг рассуждений, логов и вызовов инструментов в реальном времени. Никаких «черных ящиков».
2. **Безопасность и изоляция (Worktree Sandboxing):** Каждая задача исполняется в отдельном Git Worktree на изолированной ветке. Основной рабочий каталог разработчика защищен от случайных правок и поломок.
3. **Надежность и контроль (Interactive Checkpoints):** Интерактивное подтверждение небезопасных терминальных команд, контроль прав доступа без фальшивых эмуляций.
4. **Автономный рабочий цикл (TDD Loop `--until-success`):** Последовательное прохождение шагов (план -> red-тесты -> реализация -> green-тесты -> код-ревью -> автокоммит) с ограничением до 3 попыток на шаг.
5. **Мультиагентность и шлюз моделей:** Комбинация прямого запуска CLI-агентов (Antigravity `agy`, Claude Code `claude`, Codex app-server) и API-запросов через локальный шлюз LiteLLM для фонового аудита и рутинных задач.

## 3. Целевая аудитория и варианты использования
- Инженеры-разработчики и техлиды, ведущие сложные многофайловые рефакторинги и задачи.
- Команды, заботящиеся о приватности кода и не желающие отправлять весь контекст репозиториев через сторонние облачные прокси.
- Пользователи, активно применяющие передовые рассуждающие модели и CLI-инструменты в ежедневной разработке.

## 4. Ключевые компоненты системы
1. **Desktop Client:** Electron + React + Tailwind CSS + xterm.js для нативного управления проектами и сессиями.
2. **Execution & Run Service:** Бэкенд-сервис исполнения на Node.js, гарантирующий персистентность задач, веток, логов и одобрений.
3. **Agent Adapters:** Структурированные адаптеры к Antigravity CLI, Claude Code, Codex и ACP.
4. **Git Worktree Engine:** Менеджер изолированных рабочих деревьев с защитой от потери незакоммиченных данных.
5. **LiteLLM Gateway:** Локальный шлюз для динамической маршрутизации API-запросов между моделями.
