03 / KEEP THE CONTROLS

Give agents the work.
Keep the decisions.

Your models
Choose a preset or Custom, current CLI models, supported reasoning and permissions. Configuration stays visible beside the work.
Independent roles
Planner, executor, helpers and independent reviewers. Use one model in separate contexts or several models you select.
Your pace
Stop, manual advancement, Auto and a saved free-chat queue. After restart, continuation stays explicit.
Inspectable history
Documents, command results, reviews and earlier attempts. Retained history does not masquerade as a new successful run.
LOCAL CONTROL / EXPLICIT CONNECTIONS

The same workspace.
Access on your terms.

Open the same interface in a browser after token login. Connect other installations through the backend with read or operate scope. The assistant and Telegram use the same typed API and require local-owner setup. Native computer control is a separate permission.
