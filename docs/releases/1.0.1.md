# ZIAForge 1.0.1

**FORGE. DON'T VIBE.** The first public 1.0.1 release brings deliberate, plan-led AI development and Work tasks to an open-source desktop application.

Start with a short idea, discuss goals and technical choices, accept the foundation and implementation plan, then run agreed work with verification and independent review. Manual checkpoints and automatic advancement remain your choice; Auto never supplies a pending human decision.

## Included

- **Code:** Auto, Fix a bug, Spec first, Requirements first and Multi-model, with persistent Forge discussion, versioned documents, stage conversations and explicit plan decisions.
- **Work:** Auto, Brainstorm, Deep Brainstorm, Research and Write, with task folders, retained file inputs, questions, independent copies and document revisions.
- **Your AI connections:** supported installed Codex, Claude Code and Antigravity CLIs, plus explicitly configured OpenAI-compatible API endpoints. Presets and Custom keep model, reasoning, permissions and specialization choices.
- **Review:** independent parallel reviewers and reusable review teams. The separate architect compares anonymous reports without repository tools or reviewer identities; required blocking findings cannot be waived.
- **Workspace:** task-local chats, Markdown results, Stop and explicit resume, durable queued input, syntax-aware editing, bounded large-file access, file-manager reveal and guarded Git operations.
- **Control:** authenticated browser UI, saved remote instances, private owner-bound Telegram menus, an application architect, local CLI and MCP instructions for OpenClaw, Hermes and other clients.
- **Help:** searchable canonical English help, a separate connected-model Help assistant, 56 interface languages and labelled machine translations with offline manuals.

## Installation and important limits

Version 1.0.1 is **unsigned**: macOS packages are not notarized and Windows packages do not have Authenticode signatures. Verify the checksum and source before giving the operating system explicit permission to open a download. Automatic installation is not enabled for these unsigned packages; use manual installation or replacement after fully quitting the application.

macOS requires version 13 or later. Install Git for Code tasks and install/authenticate the selected native AI CLI separately. Exact CLI protocol versions and capabilities are listed in [provider compatibility](https://github.com/ZIAForge/ZIAForge/blob/v1.0.1/docs/PROVIDER_COMPATIBILITY.md). API compatibility, model access and subscription limits remain provider-specific.

Linux requires a graphical session and compatible runtime libraries. Saving encrypted remote-control credentials additionally requires an unlocked Secret Service or KWallet backend. DEB, RPM, AppImage and archives have different installation paths; see [platform instructions](https://github.com/ZIAForge/ZIAForge/blob/v1.0.1/docs/PLATFORM_BUILDS.md).

Working folders and worktrees are not operating-system sandboxes. Native computer control is disabled initially and can be enabled only by the local owner. The Automations panel stores definitions/counters rather than providing a recurring scheduler. Help translations are machine-translated and labelled, without a claim of native-speaker review.

## Get started

1. Install the correct package and configure a native CLI preset or explicit API connection.
2. Register a repository, choose **Requirements first** and describe the project.
3. Discuss requirements and technical choices, then accept the exact documents and implementation plan.
4. Choose the advancement and review policies; follow the retained checks, findings and artifacts.
