# ZIAForge 1.0.6

This release adds an explicit **Grok Connector v1** profile for Responses conversations. Native questions and permissions appear in the chat, and selected input images and generated images stay available in private conversation history.

## Changes

- Select Responses and Grok Connector v1 in Connections, inspect the advertised models/capabilities/usage, then apply the connection to a chat. Model reasoning and context-window choices use advertised metadata; the optional native turn limit is configurable. Unknown usage remains unknown, and a usage-period end is not a subscription expiration date.
- Answer native questions using their offered options or a custom answer. Plan interviews also expose their supported discussion/skip actions. Provider permission cards retain the exact native choices and stay separate from local file/command approvals. Decisions belong to the current session, run, turn and interaction; historical or expired cards cannot submit them again.
- Attach PNG, JPEG or WebP images through the system file dialog. Private copies are bound to that chat run: up to four images, 16 MiB each, 20 MiB combined and 32 million pixels per image. The pending-image store has a separate 128 MiB limit. Nothing is sent until the owner sends the message.
- Accepted input images and verified generated images use the existing Save and zoom viewer. Opening, saving or revisiting a cached image makes no new generation request. Failed or uncertain delivery retains the draft identities; image messages are not silently queued or moved to another connection.
- Provider web/image/question tools are explicitly selected. They never dispatch local workspace commands. Local file writes and supported commands retain separate owner approval; read-only reviews omit native image generation/editing and questions. Stop cancels the owned response, expires its interaction cards and reports an unconfirmed cancellation instead of silently retrying.
- Existing Chat Completions, ordinary Responses, Codex connector and native CLI connections keep their existing selection. Saving connection settings alone does not migrate an active chat.

## Verification and limits

Focused protocol/session/image-custody and renderer regressions, application and E2E TypeScript, full lint, Help consistency and locale-schema checks passed. The full unit run passed 1,342 of 1,350 tests; eight timing failures in six files were retained. One serial recheck of those six files passed all 59 tests without changing assertions or deadlines. An actual current-build Electron fixture exercised native decisions, input/generated image history and zoom, cancellation, full restart and normal Quit: zero renderer errors and zero surviving owned processes.

A separate source-backed Electron main session completed live read-only caller continuation, an explicitly answered native question and confirmed cancellation of a pending question. A protected existing JPEG passed exact byte/hash validation and local adapter replay without new generation. An earlier live attempt failed before response headers and was retained as uncertain; it was not automatically replayed. The later acceptance used a fresh isolated session. These results do not certify every model, a new live image generation, or packaged-platform execution.

The release pipeline builds macOS x64/ARM64, Windows x64/ARM64 and Linux x64/ARM64 from one frozen commit and checks package identity, architecture and hashes. Delivery receipts establish which jobs and asset checks completed. Build-only jobs do not repeat other-OS GUI, installer, upgrade or provider tests.

Local API command execution is supported on macOS/Linux, not Windows, and uses ordinary account permissions rather than an OS sandbox. This client does not support Grok audio or video generation/playback. The Grok profile is unavailable for tool-free Help and report-architect sessions; select a supported tool-free configuration for those roles. A connector account, supported server version, valid TLS and provider availability are still required. Advertised capabilities alone are not successful live verification.

New Grok controls have English and Russian text; the other 54 interface languages use English fallback for those controls. The changed API Help section has explicit English fallback in all 55 non-English guides; unchanged translations remain available. Schema checks do not constitute native-speaker review.

## Downloads and installation

macOS: DMG and ZIP for Intel and Apple Silicon. Windows: installer EXE and ZIP for x64 and ARM64. Linux: DEB, RPM, AppImage, tar.gz and ZIP for x64 and ARM64. Source archives, notices, a release manifest and SHA-256 checksums accompany the completed release.

Packages remain **unsigned**; macOS is not notarized. Fully quit ZIAForge before replacing the application, retain the existing user profile and verify the downloaded checksum. The stable channel does not imply code signing or automatic installation. See the [platform instructions](../PLATFORM_BUILDS.md) and [Grok connection guide](../GROK_CONNECTOR.md).
