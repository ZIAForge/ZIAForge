# ZIAForge 1.0.8

Grok Connector conversations can generate and display video when the connected server advertises verified video support. Ask for a video in the chat or attach an image and describe its motion. Available native tools include image-to-video and reference-to-video; model and server capabilities determine which request can run.

## Video in conversations

Returned MP4 files appear in an inline player with playback, pause, seeking and a Save video button. Videos are downloaded through the authenticated main process, checked against the server size and SHA-256, then retained in the private, conversation-owned media store. Playback and saving use local bytes without exposing credentials or provider URLs to the renderer. Video files are limited to 128 MiB each.

Enabling video can change the native tool profile of an existing Grok conversation. ZIAForge starts a compatible native context and carries forward bounded conversation text and owned image attachments. Pending native questions and permissions retain their original profile until answered. The explicit one-time permission opt-in from 1.0.7 also applies to eligible video operations; it does not grant local commands or file writes.

Video requires an enabled and verified capability on the connected Grok server. Standalone audio generation and video input attachments are not supported. An MP4 may contain its own audio track. This release provides natural-language chat access to native video tools, not a separate form exposing every provider parameter.

## Verification and distribution

Verification targets media validation, protected downloads, native profile migration, preserved conversation ownership and the player lifecycle. Deterministic Electron coverage checks one protected download, playback, seeking, saving and full Quit/restart without another generation. Live-provider acceptance is recorded separately from fixture results; package build receipts do not certify native GUI execution on every target.

The eight new video interface messages have translations in all 56 interface catalogs. The updated API Help section is explicitly marked as English fallback in non-English guides; unchanged translations are retained.

The release matrix includes macOS Intel/Apple Silicon DMG and ZIP, Windows x64/ARM64 installer and ZIP, and Linux x64/ARM64 DEB, RPM, AppImage, tar.gz and ZIP, together with source archives, notices, a manifest and SHA-256 checksums. Packages remain unsigned and macOS is not notarized. Fully quit ZIAForge before manually installing an update, retain the existing profile and verify the checksum.
