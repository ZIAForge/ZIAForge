# ZIAForge 1.0.7

Grok Connector conversations can now automatically approve one-time provider permissions, including image creation and editing, when the owner enables that option.

## Enable it

Open **Connections**, edit a **Grok Connector v1** connection, enable **Automatically approve one-time provider permissions**, and save. For an existing chat, apply its connection configuration again. Chat parameters include a shortcut to Connections; the chat header shows when automatic permissions are active for that run.

The option is off by default. Only a single unambiguous native `allow_once` choice can be submitted automatically, and its decision is retained in conversation history. Questions, local file writes and local commands still require their separate answers. Read-only chats keep manual provider permissions. Permanent permissions are never selected automatically; expired, ambiguous and historical requests are not automatically submitted. An uncertain acknowledgement is not retried.

## Verification and distribution

Targeted runtime, configuration and interface checks cover the changed behavior. The integrated Electron fixture verifies the opt-in control, manual questions, ambiguous permissions, automatic one-time approval, Stop and full Quit/restart without replay. This is fixture verification, separate from a live provider operation. The reported image creation/editing permission format was confirmed from existing local journals without making a new inference request.

The release pipeline produces macOS Intel/Apple Silicon DMG and ZIP, Windows x64/ARM64 installer and ZIP, and Linux x64/ARM64 DEB, RPM, AppImage, tar.gz and ZIP. Source archives, notices, a manifest and SHA-256 checksums accompany the release. Build and package identity checks do not repeat or certify native GUI/installer execution on every target.

The new controls have English and Russian text; other interface languages use English fallback for these additions. The changed API Help section is explicitly labelled as English fallback in non-English guides, retaining unchanged translations elsewhere.

Packages remain **unsigned**, and macOS is not notarized. Fully quit ZIAForge before replacing it, retain the existing profile and verify the download checksum. Installation is manual for this unsigned release. See [platform instructions](../PLATFORM_BUILDS.md) and the [Grok connection guide](../GROK_CONNECTOR.md).
