# ZIAForge 1.0.2

This stable maintenance release connects the application and public project information to the official landing at [ziaforge.studio](https://ziaforge.studio), alongside the refreshed multilingual documentation website.

## Changes

- The About window, native Help menu and package homepage point to **https://ziaforge.studio**. The application link reuses the existing translated label across all 56 interface languages.
- The [documentation website](https://ziaforge.github.io/ZIAForge/) remains the destination for the canonical product guide in all 56 interface languages, with search, responsive navigation and right-to-left layouts.
- README and public website navigation distinguish the landing, product help and GitHub source/download destinations.
- Application packages receive the stable **1.0.2** version and are compiled from one frozen release source.

Code and Work behavior, Forge decisions, model settings and review policies remain as described in [1.0.1](https://github.com/ZIAForge/ZIAForge/releases/tag/v1.0.1). This update does not introduce a new workflow or repeat native-platform or GUI certification.

## Downloads and installation

Choose the operating system and CPU architecture, then verify the download against the release's `SHA256SUMS`.

| Platform | Architectures | Packages |
| --- | --- | --- |
| macOS | Intel x64 · Apple Silicon ARM64 | DMG · ZIP |
| Windows | x64 · ARM64 | Installer EXE · ZIP |
| Linux | x64 · ARM64 | DEB · RPM · AppImage · tar.gz · ZIP |
| Source | Platform-independent | tar.gz · ZIP |

Packages remain **unsigned**: macOS is not notarized and Windows has no Authenticode signature. Installation and replacement are manual; fully quit the application first. A generated package or cross-build does not prove native execution on every target. Refer to [platform installation instructions](https://github.com/ZIAForge/ZIAForge/blob/v1.0.2/docs/PLATFORM_BUILDS.md) for prerequisites.
