# ZIAForge 1.0.10

Claude Connector v1 is now a separate API profile using Anthropic Messages. In **Connections**, select the profile, supply its HTTPS origin without `/v1`, save the key, and inspect the connector before selecting the model and tools. Existing API and CLI connections keep their configured protocols.

## Claude conversations

- **Caller mode** uses the local task workspace. File writes and supported local commands require explicit owner approval.
- **Native mode** uses the connector's remote workspace and explicitly selected native tools. Native permissions and questions have separate interactive cards; they never grant local tool access.
- Model choices, reasoning effort and thinking controls use the live catalog. Unknown limits stay unknown; subscription renewal dates remain explicitly labelled manual information.
- Images, including GIF, and PDF/text documents use private owned attachment copies. Native file artifacts show their type, size and revision, with Save for the current or earlier immutable version.
- Saved completed conversations continue from their exact owned response. Interrupted or uncertain tool operations and decisions are never automatically replayed. Stop reports cancellation uncertainty if the server cannot confirm completion.

File artifacts are download-only in this profile; HTML and SVG are never embedded. This release does not add native image/video/audio generation. Local API command supervision remains available on macOS/Linux only. See the [complete connector guide](../CLAUDE_CONNECTOR_V1.md) for limits and ownership rules.

## Localization and verification

The new connector controls and the API Help section are available across all 56 configured interface languages. Non-English Help is machine-translated and marked accordingly; native-language human review is not claimed. The separately maintained Updates Help section still displays its explicit English fallback where translation is pending.

Verification covers focused transport, ownership, attachment, interaction and runtime regressions, TypeScript, lint and a fresh Electron fixture flow. The fixture exercises profile configuration, private GIF/PDF attachment copies, permissions, questions, immutable file revisions, Save and full Quit/reopen without replay. Live checks separately cover catalog discovery, approved local reads/writes/commands, completed-session continuation after runtime restart, native questions, a text document, digest-verified native artifacts and confirmed Stop. A reproduced Stop-status defect was corrected and the failed receipt retained. These live and fixture checks do not constitute packaged runtime certification on every platform.

## Distribution

The release matrix includes macOS Intel/Apple Silicon DMG and ZIP, Windows x64/ARM64 installer and ZIP, Linux x64/ARM64 DEB, RPM, AppImage, tar.gz and ZIP, plus source archives, notices, a manifest and SHA-256 checksums. Platform jobs compile and verify package integrity; they do not repeat installer, GUI or live-provider checks on every OS. Packages are unsigned and macOS packages are not notarized.

Version 1.0.9 can obtain this release through **Settings → Updates**. Earlier versions require a manual upgrade to acquire that updater. Keep the normal OS trust prompts enabled.
