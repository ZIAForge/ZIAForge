# ZIAForge 1.0.5

This release adds Responses API conversations with tools and private generated-image cards. Click an image to inspect it in a larger viewer, zoom, switch to 100% or fit the window, and drag to examine details.

## Changes

- Explicit Responses transport alongside existing Chat Completions connections. Function-call continuations retain the original call identity, provider tools are displayed separately from local tools, and interrupted requests are not automatically resent.
- Generated PNG, JPEG and WebP images are validated, stored privately, shown outside collapsed tool output and saved through the native file dialog. Opening, zooming, saving and reopening cached images do not request a new generation.
- The image viewer supports zoom buttons, keyboard shortcuts, actual size, fit, scrolling and dragging. Escape closes it and returns focus to the chat image. Changing the image or chat owner closes the viewer and releases the old preview.
- **Set up Responses** opens an explicit draft for an existing connection and preserves its key when the endpoint is unchanged. Saving alone keeps existing chats on their pinned transport; select the same connection in the chat and click **Apply**. The header shows the protocol actually used by that run, and history is retained.
- Responses connections can opt into local commands on macOS/Linux. Each command needs owner approval; this is not an operating-system sandbox. Windows does not advertise that command tool. The optional Codex connector profile supports its provider-progress and cancellation extension; it is never inferred from the endpoint address.
- Includes the Windows settings persistence fix from 1.0.3. No automatic connection migration or new provider billing path is introduced.

## Verification and limits

Targeted API, credential-retention, session, image and renderer regressions cover the changed behavior. One integrated packaged Mac fixture checks explicit migration, tools, image rendering/zoom/save, Stop and full Quit/Resume. Fixture protocol checks are separate from live provider inference. Release delivery records and checksums identify the exact completed packages and retained verification results; a planned or blocked check is not a pass.

Fresh native build-only jobs compile and validate package identity/architecture for macOS x64/ARM64, Windows x64/ARM64 and Linux x64/ARM64. They do not repeat other-OS GUI, installer, upgrade or provider tests. This change does not claim a new complete regression-suite pass.

The new interface controls have English and Russian text; remaining interface languages use English for those new controls while retaining their existing translations. The changed API Help section has an explicitly labelled English fallback; unchanged translated sections remain available. Native-speaker review is not claimed.

## Downloads and installation

macOS: DMG and ZIP for Intel and Apple Silicon. Windows: installer EXE and ZIP for x64 and ARM64. Linux: DEB, RPM, AppImage, tar.gz and ZIP for x64 and ARM64. Source, notices, build receipts and SHA-256 checksums accompany the release.

Packages remain **unsigned**; macOS is not notarized. Fully quit ZIAForge before replacing the application, retain the existing user profile, and verify the downloaded checksum. The stable channel does not imply code signing or automatic installation. See the [platform instructions](../PLATFORM_BUILDS.md).
