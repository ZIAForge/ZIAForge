# ZIAForge 1.0.9

Check for a newer release directly in **Settings → Updates**. The official GitHub repository and Stable channel are configured by default. The panel shows the installed version, available version and download progress, with a shortcut from General settings.

Choose **Update** to download the matching package and install it after ZIAForge completes its normal shutdown. Save editor changes first. User profiles, projects, settings and conversation history are retained. Optional automatic checks can download a package; installation remains an explicit local action.

## Installation and recovery

The updater checks GitHub asset metadata against the release manifest, platform, architecture, size and SHA-256 before preparing an installation. Supported paths include writable macOS app bundles, Windows installer installations, Linux AppImages and distribution-owned DEB/RPM installations. Unsupported portable layouts, source checkouts and read-only/translocated apps expose the manual release path. Operating-system authentication and trust prompts remain in effect.

Download or integrity failure leaves the current installation intact. macOS/AppImage replacement retains a backup for recovery. No abandoned staging is installed on an ordinary restart. See [application updates](../UPDATES.md) for the precise lifecycle and platform limits.

Versions through 1.0.8 need a manual upgrade once to acquire the new updater. Packages remain unsigned; macOS packages are not notarized. Checksums establish matching bytes, not an independent signing identity.

## Verification and distribution

Verification passed 23 focused backend/UI tests, application and E2E TypeScript checks, ESLint, Help/locale consistency, and one current-build Electron fixture covering source/channel persistence, verified download, the editor guard and full Quit/restart. Disposable Mac filesystem fixtures exercised parent-exit waiting, replacement, rollback and profile preservation; the published 1.0.8 ZIP was used only to verify package-format compatibility. Deterministic fixtures are separate from native operating-system upgrade certification. Packaging all six OS/architecture targets does not mean each platform's installer was executed.

New update controls are translated in all 56 interface catalogs. The revised Help section is explicitly served in English in non-English guides, with unchanged translated sections retained. Native-language human review is not claimed.

The release matrix includes macOS Intel/Apple Silicon DMG and ZIP, Windows x64/ARM64 installer and ZIP, Linux x64/ARM64 DEB, RPM, AppImage, tar.gz and ZIP, source archives, notices, a manifest and checksums.
