# Help translations

The complete English reference is [../en.json](../en.json). Translated bodies use the same section IDs/order, field counts and contract paths. No copied English file may be advertised as a translation.

Register incomplete work as `draft`; it falls back to English. A complete machine translation uses `machine-translated`, an exact `translatedSourceSha256` and a declared method. It is displayed with a machine-translation notice, without human-review claims. `reviewed` is reserved for an actual proficient human review tied to the current English hash. Missing or stale source bindings are never silently served as current translations.

[../locales.json](../locales.json) records per-language status. The generated [coverage table](../LOCALES.md) links offline manuals. [../../HELP_MAINTENANCE.md](../../HELP_MAINTENANCE.md) explains source freeze, bounded native translation, protected technical identifiers, provenance, review and regeneration. Raw native-provider evidence stays outside the repository.
